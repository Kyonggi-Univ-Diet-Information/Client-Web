# Let's Eat Kiryong! · 기룡아 밥먹자!

기룡아 밥먹자! 는 경기대학교 학생들을 위한 교내 식당 정보 서비스예요.<br/>
학생들이 교내 식당의 메뉴와 실제 이용자들의 솔직한 리뷰를 바탕으로, 매 끼니마다 더 만족스러운 선택을 할 수 있도록 돕고 있어요.
